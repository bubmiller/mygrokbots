# mygrokbots

Durable knowledge log for Steve's bots. Chat memory dies; this repo keeps decisions, shipped work, and standing preferences.

## Layout

- One folder per bot: `captian/`, `carrie/`, `emily/`, `robin/`, `allen/`, `brad/`, `coach/`, `tracy/`
- One markdown file per day: `YYYY-MM-DD.md`

## What to log

- Decisions
- Shipped work
- Standing preferences

## What never to log

- Secrets, tokens, passwords
- Customer data
- Private messages

## Cadence

- Daily write at 9:00 PM Eastern (America/New_York)
- If nothing happened that day, stay quiet (no empty file)
